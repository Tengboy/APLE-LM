# Main-figure revision 0.2

2026-10-04: all legends now have white opaque backgrounds and visible borders.
The former four-panel grid plot becomes two panels, each combining both array
sizes; two full-sample BCRB horizontal lines are added to its accuracy panel.
Array grouping and distance are separate main figures. The iteration canvas is
11.5 by 11.5 cm with two vertical panels and iterations 1 through 10.
Figures follow journal order; CDF follows SNR performance. See FIGURES.md.

Only display layout, figure numbering and associated documentation changed.
Numerical source files and reference CSV values are unchanged. Version 0.1's
validation record remains historical evidence; validation.json records the
current display audit separately. The runner accepts the new figure numbering
and semantic experiment names. Use a new output directory when a source-identity
check rejects a checkpoint from an earlier release.
